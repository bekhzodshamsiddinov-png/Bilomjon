# BILIM AI — portable startup starter

**Status:** 0.2 specification handoff (v0.1 demo retained) product specification + clickable concept prototype. Not a deploy-ready educational service.

Open `app/index.html` to explore the offline demo. Read `docs/PRD.md` for objectives, `docs/BACKLOG.md` for what to build next, `docs/HANDOFF.md` to transfer to ChatGPT / Claude Code.

**Principle:** child learning gains and parental empowerment first. Architecture for all Uzbekistan primary-school grades and subjects; validate each academic year's actual approved syllabi before publishing content.

This ZIP contains no credentials or real child data. Keep a copy in your GitHub repository for portability.
