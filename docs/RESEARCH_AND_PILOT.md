# Discovery and pilot plan (not conducted)

## Interview guide: parent (15–20 min, 20 participants target)
1. Tell me about the last time homework was hard for your child. What did you do?
2. Which subject/grade, device and language? How long did it take?
3. What resources did you try? What failed? What did you pay (if anything)?
4. How do you know whether your child *understands* versus copies an answer?
5. What worries you about an AI tutoring tool (privacy, error, screen time)?
6. Would 10-minute guided co-study help? Observe task before showing pricing.
7. If useful, how would you prefer to pay? Never ask for card information.

## Educator interviews (8–12)
Biggest misconceptions by grade; curriculum variance, example solutions, readability, feedback thresholds, parent involvement, acceptable homework assistance, pilot risks.

## Child sessions (parent consent, supervised)
Observe navigation and concrete tasks; no personal identifiers recorded; never pressure child to participate. Ask child to explain problem in own words. End if distressed or bored.

## Pilot protocol
- 30–50 families is an aspirational exploratory pilot, not proof of effectiveness.
- Pre-register primary learning outcome (fresh equivalent transfer items) and stop criteria; baseline, post, 2–4 week retention where feasible.
- Ideally comparison group on same content using current tools, avoid selection bias; report sample size, missingness and confidence limits.
- Track task success, guardian confidence, lesson duration, accessibility, erroneous AI explanations and cost per learning gain.
- Safety escalation owner and feedback channel must be defined before recruiting; require formal legal/privacy review of data collection.

## Go / no-go
Proceed only if teachers find content correct, children can complete tasks, no severe safety/privacy failures, and preliminary learning/parent feedback justify expansion. Do not promise results in advance.
